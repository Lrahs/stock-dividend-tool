# 攒股收息小工具

![软件界面](docs/images/app-4.4.0.png)

面向长期持股与分红研究的 Windows 桌面工具。查看分红现金流估算、跟踪每月目标、研究公司指标，并记录自己的研究笔记。

**当前版本：4.4.0 · Windows x64 · MIT**

## 下载与安装

前往本仓库右侧 **Releases**，打开 **v4.4.0**，下载 `stock-dividend-tool Setup 4.4.0.exe` 并运行。普通用户不需要安装 Node.js，也不需要下载源码。

本发布提供 Windows x64 安装包；其他系统暂未提供安装包。桌面窗口最小尺寸为 1100 × 720。

## 主要功能

- 当前持仓：预估月度与年度分红、总市值、股息率、每月目标进度，以及板块和板块内部配置图。
- 股票观察／股票研究：股价、分红、估值、成长、财报、股东与营运资金分组展示；支持搜索、添加和删除观察股票。
- 持仓管理：加入持仓、调整股数、按行业筛选。
- 股息率排行：按行业与价格区间筛选。
- 研究笔记：自动保存。
- Excel 导出：选择股票，导出各项指标快照。
- 薰衣草紫界面和统一的钱袋应用图标。

## 快速开始

1. 打开“股票观察／股票研究”，选择或添加股票。
2. 点击“全部刷新”；当前自动行情刷新覆盖沪深 A 股，港股暂不在自动刷新范围。
3. 点击“加入持仓”。首次加入默认 100 股，并在当前页面显示成功提示。
4. 进入“当前持仓”，将股数修改为自己的实际数量。
5. 在研究页记录笔记，需要时导出 Excel。

分红数据是税前估算，并非实际到账记录。当前每月目标固定为 ¥5,000；港币折算使用固定系数 0.92。缺失行情会影响估算与图表，详细口径见[使用文档](docs/USER_GUIDE.md)。
