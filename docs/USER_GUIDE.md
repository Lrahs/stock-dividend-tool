# 4.4.0 使用文档

## 安装、升级与卸载

下载 Releases 中的 4.4.0 Windows x64 安装包并运行，按安装程序完成安装。通过桌面或开始菜单快捷方式启动。更新前退出软件，备份数据目录，再运行新安装包。卸载可通过 Windows 设置的“已安装的应用”完成；卸载后的数据保留行为应以卸载程序实际选项为准，卸载前先备份。

软件不需要注册账号。获取股票行情需要联网。首次启动会加载预设观察列表，股数初始为 0，指标可能在刷新成功后才显示。

## 股票观察／股票研究

点击左侧导航进入页面，使用上方行业筛选或左侧股票列表选择股票。搜索支持代码或名称；在线搜索候选主要覆盖沪深 A 股。添加时填写代码、名称并选择行业，点击“添加观察股票”。重复代码不会再次添加。

详情按股价区间、分红水平、估值、成长、财报、股东和营运资金分类。点击“加入持仓”首次设置 100 股，已有股数保持不变；操作后保留当前页面和行业筛选，出现约 4 秒的成功提示，提示也可手动关闭。该操作只是记录持仓，不会向券商下单。

研究笔记在输入后自动保存。删除观察股票会移除该股票及其记录，操作前请确认需要保留的内容；列表至少保留一只股票。

## 当前持仓

该页面只显示股数大于 0 的股票。调整股数后自动保存；输入按 100 股向下取整，负数归为 0。例如 399 股会保存为 300 股。设置为 0 后该股票离开持仓列表，但仍在观察列表中。

板块占比和所选板块内部占比位于持仓明细上方，先查看图形，再查看具体持仓。

## 现金流与目标口径

- 市值：股价 × 股数；港股使用固定 0.92 的港币兑人民币折算系数，当前不是实时汇率。
- 加权股息率：对具备市值及股息率数据的持仓，按市值加权。
- 年度估算：总市值 × 加权股息率；月度估算再除以 12。
- 月度目标：固定 ¥5,000，显示目标完成比例及差额；当前界面没有修改目标的入口。

数据缺失时，指标可能显示“暂无数据”。总市值可能只包含有价格的股票；股息率数据不完整时，加权股息率只使用数据齐全的股票，而年度估算仍按上述总市值计算。因此请先核对所有持仓的行情和股息率。部分价格缺失时，配置图会暂按股数展示，并显示相应说明。

估算不扣税、不反映每个月真实到账时间，也不保证未来分红。软件没有分红到账流水、自动交易或实时汇率功能。

## 刷新与排行

点击“全部刷新”更新行情并显示进度。当前仅自动刷新沪深 A 股；港股不在此刷新范围。接口异常或被限流时可能出现部分失败，可稍后重试。软件不会保证每个指标在每次刷新时都能取得，未取得的字段可能保留之前的数据。

“股息率排行”支持选择行业、输入最低和最高股价；数据应在刷新后核对，排行不构成买卖推荐。

## 行业与导出

在股票列表点击“管理行业”，添加、重命名或删除行业时遵循页面提示；不要重复创建同名行业。

点击“导出 Excel”，搜索并勾选需要导出的股票，点击导出按钮。文件是股票指标快照，不是可一键恢复的数据备份；当前没有 Excel 导入恢复入口。

## 数据备份

正式 Windows 安装版的数据目录通常是 `%APPDATA%\stock-dividend-tool`，其中 `stock-data.json` 保存股票、持仓和笔记。自定义行业等也使用本地浏览器存储，建议关闭软件后备份整个目录，而不仅是 JSON。若开发环境或后续产品名称改变，实际目录可能不同。

恢复时关闭软件，把备份内容放回对应目录，覆盖前另存一份当前目录。不要公开上传这个目录、JSON 文件或个人 Excel 导出文件。

## 常见问题

**加入持仓后找不到股票？** 进入“当前持仓”，选择“总览”，检查股数是否大于 0。

**股数为何变小？** 当前版本按 100 股向下取整。

**港股刷新后仍无数据？** 当前自动行情刷新仅覆盖沪深 A 股。

**升级后数据不见了？** 检查是否使用相同 Windows 用户、同一产品的数据目录，并核对备份。不要反复删除目录或清除本地缓存。

**软件页面截图有数据，但我的页面空白？** 仓库截图展示界面结构；初始没有真实持仓，需要自行记录股数并获取行情。
